Bienvenue dans Suivi de Budget

Une application simple et élégante pour suivre vos revenus et dépenses, comprendre où va votre argent, et atteindre vos objectifs financiers. Vos données restent sur votre appareil — rien n'est envoyé sur internet.

💡
Pas besoin de créer un compte L'application fonctionne directement dans votre navigateur. Vos données sont sauvegardées automatiquement sur votre ordinateur.

À quoi sert cette application ?

📥

Enregistrer vos finances

Ajoutez chaque revenu (salaire, freelance…) et chaque dépense (loyer, courses…) au fil du temps.

📊

Visualiser en un coup d'œil

Le tableau de bord affiche immédiatement vos revenus totaux, vos dépenses et votre solde disponible.

🍩

Comprendre vos dépenses

Un graphique montre la part de chaque catégorie (loyer, transport, alimentation…) dans vos dépenses.

📅

Suivre mois par mois

Filtrez par mois pour analyser chaque période et comparer votre évolution dans le temps.

💰

Fixer des budgets

Définissez un plafond de dépenses par catégorie et suivez si vous restez dans les limites.

🎯

Atteindre vos objectifs

Créez des objectifs d'épargne (vacances, voiture…) et suivez votre progression vers chacun.

Premiers pas

Vous venez d'ouvrir l'application pour la première fois ? Voici comment la prendre en main en moins de 5 minutes.

Votre première transaction

1

Choisissez le type de transaction

En haut du formulaire "Nouvelle transaction", deux boutons vous permettent de basculer entre Revenu et Dépense. Le bouton sélectionné se colore en vert (revenu) ou en rouge (dépense).

↑ Revenu
↓ Dépense
2

Saisissez la description

Écrivez ce que c'est : "Salaire de juin", "Loyer", "Courses Lidl"… Soyez précis pour retrouver facilement vos transactions plus tard.

3

Entrez le montant

Tapez uniquement le nombre, sans le symbole €. Exemple : 850 pour 850 €. Vous pouvez mettre des décimales : 14.90 pour 14,90 €.

4

Vérifiez la date

La date d'aujourd'hui est remplie automatiquement. Vous pouvez la modifier si vous entrez une transaction rétrospectivement (une dépense oubliée de la semaine dernière, par exemple).

5

Pour une dépense : choisissez la catégorie

Un menu déroulant apparaît uniquement pour les dépenses. Choisissez la catégorie la plus proche. Si rien ne correspond, utilisez "Autres".

6

Cliquez sur "Ajouter"

La transaction apparaît instantanément dans votre historique et le tableau de bord se met à jour. Rien à sauvegarder manuellement — c'est automatique.

✅
Bonne habitude à prendre Enregistrez vos transactions le soir même ou le week-end. Plus vous attendez, plus vous risquez d'oublier des dépenses. 5 minutes par semaine suffisent à tenir un budget à jour.

Que voir après l'ajout ?

Dès que vous ajoutez votre première transaction, l'application affiche :

  • Le tableau de bord se met à jour : revenus, dépenses, solde
  • La transaction apparaît dans l'historique en bas de page
  • Si c'est une dépense, elle s'ajoute au graphique de répartition
💾
Sauvegarde automatique Vos données sont sauvegardées automatiquement dans votre navigateur à chaque modification. Vous pouvez fermer l'onglet et revenir plus tard : tout sera là.

Gérer les transactions

Tout ce que vous pouvez faire avec vos transactions : ajouter, modifier, supprimer, rechercher, annoter et automatiser.

Passez la souris sur une ligne de l'historique : un bouton crayon ✏ apparaît à droite. Cliquez dessus pour ouvrir une fenêtre de modification pré-remplie.

Vous pouvez changer : le type (revenu/dépense), la description, le montant, la date, la catégorie et la note. Cliquez sur "Enregistrer" pour valider, ou "Annuler" pour ignorer vos changements.

↑ Au survol, les boutons apparaissent

Passez la souris sur une transaction : un bouton corbeille 🗑 apparaît à droite, en rouge. Cliquez dessus pour supprimer définitivement la transaction.

⚠️
La suppression est définitive Il n'y a pas de corbeille ni d'annulation. Avant de supprimer, assurez-vous que c'est bien cette transaction que vous voulez effacer.

Dans le formulaire d'ajout, un champ "Note (optionnelle)" vous permet d'ajouter un commentaire libre. Par exemple :

  • Pour un loyer : "inclut charges"
  • Pour des courses : "repas du week-end avec la famille"
  • Pour une dépense médicale : "remboursement prévu par la mutuelle"

La note apparaît en italique sous la date dans l'historique. Elle est aussi cherchable via la barre de recherche.

Certaines dépenses reviennent chaque mois au même montant : loyer, abonnements Netflix, Spotify, gym… Pour ne pas avoir à les ressaisir chaque mois :

1

Lors de l'ajout, cochez "Répéter chaque mois"

La case à cocher se trouve juste avant le bouton "Ajouter".

2

La transaction est marquée avec le badge ↻

Dans l'historique, un badge doré ↻ apparaît à côté du nom pour identifier les transactions récurrentes.

3

Chaque mois, une copie est créée automatiquement

Au prochain chargement de l'application (au début du mois), une copie est ajoutée pour le mois en cours, à la même date.

💡
Idéal pour Loyer, crédit, abonnements (streaming, salle de sport, transport)… Tout ce qui a le même montant chaque mois.

Au-dessus de l'historique, une barre de recherche vous permet de filtrer instantanément les transactions. La recherche porte sur :

  • La description de la transaction
  • La note ajoutée

La liste se met à jour à chaque lettre tapée. Pour effacer la recherche, cliquez sur le ✕ à droite, ou effacez le texte.

Au-dessus de l'historique, deux boutons vous permettent d'échanger des données avec d'autres outils :

↓ Export — Télécharger vos données

Cliquez sur "↓ Export" pour télécharger toutes vos transactions au format CSV. Ce fichier s'ouvre dans Excel, Google Sheets ou LibreOffice. Utile pour :

  • Faire une sauvegarde de vos données
  • Analyser en détail dans un tableur
  • Transférer vers une autre application

↑ Import — Importer depuis votre banque

Cliquez sur "↑ Import" et sélectionnez un fichier CSV. L'application reconnaît automatiquement les colonnes Date, Description et Montant. Les montants positifs deviennent des revenus, les négatifs des dépenses.

🏦
Exporter depuis votre banque La plupart des banques en ligne (Boursorama, N26, Revolut, Société Générale…) permettent d'exporter votre historique en CSV. Téléchargez-le et importez-le ici.

Filtre par mois

Juste sous la carte Tendances, des boutons permettent de sélectionner un mois spécifique. Quand un mois est sélectionné :

  • Le tableau de bord n'affiche que les chiffres de ce mois
  • Le graphique ne montre que les dépenses de ce mois
  • L'historique est filtré sur ce mois
  • Les tendances comparent ce mois au précédent

Cliquez sur "Tous" pour revenir à la vue globale. Utilisez les flèches ← → pour naviguer de mois en mois.

Graphique de répartition

Le graphique en anneau (donut) montre la part de chaque catégorie dans vos dépenses totales. Survolez une portion pour voir le montant exact. En dessous, la légende détaille chaque catégorie avec son pourcentage et son montant.

💡
Règle des 50/30/20 Une règle financière populaire suggère de consacrer 50% des revenus aux besoins essentiels (loyer, courses), 30% aux envies (loisirs, restaurant), et 20% à l'épargne. Le graphique vous aide à vérifier où vous en êtes.

Vue annuelle

Plus bas dans la page, un graphique en barres montre les 12 derniers mois côte à côte, avec les revenus (vert) et les dépenses (rouge) pour chaque mois. Idéal pour repérer les mois où vous avez beaucoup dépensé (vacances, fêtes de fin d'année…) et planifier en conséquence.

📅
La vue annuelle ne filtre pas Elle affiche toujours les 12 derniers mois, indépendamment du filtre mois que vous avez sélectionné. C'est voulu : c'est une vue de référence globale.

Fonctionnalités avancées

Budget par catégorie, objectifs d'épargne, mode clair… Ces fonctionnalités vous aident à aller plus loin dans la gestion de vos finances.

💰 Budget par catégorie

Fixez un plafond mensuel pour chaque catégorie de dépenses. Par exemple : ne pas dépenser plus de 300 € en alimentation ou 100 € en divertissement.

1

Repérez la section "Budget par catégorie"

Elle se trouve après le graphique annuel, à gauche sur grand écran.

2

Cliquez sur "+ Définir" à côté d'une catégorie

Un champ de saisie apparaît. Tapez le montant maximum que vous souhaitez dépenser pour cette catégorie ce mois-ci.

3

Validez avec ✓

Une barre de progression apparaît montrant combien vous avez dépensé par rapport au budget fixé.

🎯
Conseil : commencez par observer Pendant le premier mois, ne fixez pas de budget. Regardez simplement combien vous dépensez naturellement dans chaque catégorie. Ensuite, fixez des budgets réalistes basés sur vos vraies habitudes.

🎯 Objectifs d'épargne

Créez des objectifs concrets : un voyage, l'achat d'un ordinateur, un fonds d'urgence… et suivez votre progression.

1

Cliquez sur "+ Ajouter"

Dans la section "Objectifs d'épargne" (à droite de la section Budget).

2

Nommez votre objectif et fixez le montant cible

Exemple : "Vacances Grèce" avec un objectif de 2 000 €. Vous pouvez aussi indiquer combien vous avez déjà épargné.

3

Mettez à jour votre épargne régulièrement

Cliquez sur "Mettre à jour l'épargne" pour modifier le montant épargné. Ou utilisez "Utiliser le solde" pour automatiquement affecter votre solde actuel à cet objectif.

Questions fréquentes

Les réponses aux questions les plus courantes des utilisateurs.

Oui, chaque modification est sauvegardée automatiquement dans votre navigateur (localStorage). Vous pouvez fermer l'onglet, éteindre votre ordinateur, et revenir plus tard : toutes vos données seront là.

Aucune action de votre part n'est nécessaire : pas de bouton "Enregistrer", pas de compte à créer.

Oui. Vos données ne quittent jamais votre ordinateur. Elles sont stockées dans votre navigateur, localement. Aucun serveur ne les reçoit, aucune entreprise n'y a accès.

La seule façon pour quelqu'un d'y accéder est d'avoir un accès physique à votre ordinateur et à votre navigateur.

Vider le cache du navigateur (ou supprimer les données du site) effacera vos transactions. Pour éviter de les perdre :

  • Exportez régulièrement vos données en CSV (bouton "↓ Export")
  • Conservez ce fichier CSV en lieu sûr (dossier Documents, cloud personnel…)
  • En cas de besoin, réimportez-le avec le bouton "↑ Import"

Si vous changez de navigateur ou d'ordinateur, l'export/import CSV est la seule façon de transférer vos données.

Oui, l'interface s'adapte aux petits écrans. Sur mobile, certains éléments comme les badges de catégorie sont masqués pour gagner de la place, mais toutes les fonctionnalités restent accessibles.

Pour arrêter une transaction récurrente, modifiez-la (bouton crayon ✏) et décochez la case "Répéter chaque mois". Les copies déjà générées dans les mois passés restent dans l'historique.

L'application est configurée pour afficher les montants en euros (€). Il n'y a pas d'option pour changer la devise. Vous pouvez toutefois entrer des montants dans n'importe quelle unité et ignorer le symbole €.

Pour effacer toutes vos données, vous pouvez :

  1. Supprimer les données du site dans les paramètres de votre navigateur
  2. Ou supprimer manuellement chaque transaction (moins pratique)

Dans Chrome : Paramètres → Confidentialité et sécurité → Cookies et autres données → Voir toutes les données → chercher "localhost" → Supprimer.

L'application est conteneurisée avec Docker. Sur n'importe quel ordinateur où Docker est installé :

  1. Copiez le dossier du projet
  2. Ouvrez un terminal dans ce dossier
  3. Tapez : docker compose up --build
  4. Ouvrez http://localhost:8080 dans le navigateur

N'oubliez pas d'exporter vos données en CSV pour les importer sur le nouvel ordinateur.

Conseils pour bien utiliser l'application

📆
Saisie hebdomadaire Prenez 5 minutes chaque dimanche pour saisir toutes les transactions de la semaine. C'est plus simple que de tout faire d'un coup en fin de mois.
📸
Photographiez vos reçus Prenez en photo vos reçus et tickets de caisse pour ne rien oublier. Saisissez la note le soir même.
📊
Analysez en fin de mois En fin de mois, sélectionnez le mois dans le filtre et passez 10 minutes à analyser : où est allé votre argent ? Qu'auriez-vous pu éviter ? Ajustez vos budgets pour le mois suivant.
💾
Exportez chaque trimestre Tous les 3 mois, exportez vos données en CSV et sauvegardez le fichier. C'est votre filet de sécurité si votre navigateur perd les données.
